IMPORTANT BEFORE UPLOADING
1. Keep your existing supabase-config.js. Do NOT replace it with a placeholder.
2. This package is a standalone frontend refresh. It stores added titles in this browser's localStorage; it does NOT automatically connect movie records to your Supabase database.
3. The Admin Panel is a browser-local demo manager, not secure admin authentication. Do not rely on it for private/admin-only content on a public site.
4. To open the Admin Panel locally, press Ctrl+Shift+A on a computer. On phones, use browser console/devtools is not practical; a visible admin button can be added after the design is confirmed. Do not publish admin functionality as a secret security mechanism.
5. AUTO POSTER: In Admin Panel, enter movie title, enter your own OMDb API key, tap Auto Poster, review results, then Save Movie. OMDb may not have every title. The API key is saved in localStorage in this browser. Get a key from the official OMDb API website (omdbapi.com).
6. Download only works as a best-effort link for direct URLs you are authorised to download. It cannot bypass YouTube, streaming-site, DRM, or other provider restrictions.
7. Demo titles use public image URLs as examples; replace them with posters/images you have rights to use.
8. This is a replacement frontend package and may not exactly reproduce every detail of your earlier repository version. Make a backup/commit before replacing files. If you want to preserve the old design exactly, restore the earlier index.html/style.css/script.js from GitHub History before merging specific features.
